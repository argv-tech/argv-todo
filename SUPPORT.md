# Getting help

Start with the [README](README.md) for installation, storage locations, and keybindings. Run `argv-todo --help` for command-line options, or press `?` in the app for help.

For a question, open an [issue](https://github.com/argv-tech/argv-todo/issues) with a descriptive title. For a reproducible bug or a feature proposal, use the matching issue form.

Include your app version (`argv-todo --version`), operating system, terminal emulator, and the steps you tried. For rendering issues, include the terminal dimensions. For build issues, include `rustc --version` and the relevant error output.

Use fictional tasks and a temporary database for reproductions. Remove personal data from screenshots and logs. Report vulnerabilities through the process in [SECURITY.md](SECURITY.md).

Support is provided by volunteers as time permits.
